# secret-date-card

A mobile-first web app styled like a scratch-off lottery ticket. Scratch
a panel to reveal a date.

See [docs/SPEC.md](docs/SPEC.md) for the full spec (data model, routes,
interaction) and [CLAUDE.md](CLAUDE.md) for project/agent context and
commands.

## Quick start

```
npm install
npm run dev
```

## Editing the ticket

All ticket content lives in `src/data/dateOptions.ts` — add, remove, or
edit entries there.
